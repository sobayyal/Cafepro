# Cafepro

Cafepro is a web-based cafe management system designed to simplify day-to-day operations such as menu management, order tracking, and sales monitoring. It aims to streamline workflows and enhance customer experience for cafe owners and staff.

## Features

- User authentication and access control
- Menu item creation and editing
- Order placement and status tracking
- Dashboard with sales reports and analytics
- Clean and responsive UI

## Technologies Used

- **Frontend:** React.js
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Authentication:** JWT (JSON Web Tokens)
